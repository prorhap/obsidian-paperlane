# Paperlane 0.2.2

Use Send to Instapaper for the file context menu, preview heading, and send button. The current-note command is now Send current note to Instapaper. Command IDs and settings remain unchanged.

Tokens are configured in Settings → Paperlane → Personal access token (개인 액세스 토큰) → Link. Create a secret with a descriptive ID and enter the token in the Secret field. The plugin stores only a reference to Obsidian’s secret storage.
